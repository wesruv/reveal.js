Text Flow

  • How text behaves and tags like <strong> & <em>
  • Inline* elements mimic text flow
  • White space matters* (*up to one space!)
With no CSS, HTML will fall back to a textual flow
Doesn’t care about widths, heights, margins, padding, etc

Layout Flow

  • White space agnostic
  • Properties like:
    • Grid
    • Flexbox
    • Table
    • CSS Columns

It's not wrong to break document flow, it is gutsy
He'll do exactly what you say, even when it doesn't make sense
Lose the safeguards of document flow that made sure content is legible
He's been grumpy about all these new-fangled screen sizes
Test your CSS on many screen sizes, px densities, and browsers when you bring out this guy

Document Flow Breakers:

Document Flow

position: absolute, fixed, sticky

These will behave very rigidly and can cause overlap or bugs on differently sized screens.
Position fixed is particularly grumpy about smaller sized screens and zooming

Mess with Document Flow

  • position: relative
    (when top, right, bottom or left are set)
  • transform
  • negative margin or padding
These can cause overlap and can get a little weird
To get a modal like this, you have to break document flow
But notice inside of it, we're back to regular document flow

TL:Didn't think your cartoons were funny

  • Breaking the flow can cause complicated, hard to solve problems.
  • Try to use Flow-friendly CSS first.
  • Breaking flow isn't 'bad', but should be used sparingly and carefully.

Grid Units & Helpers

fr

Distributes free space in a grid track

grid-template-row: 1fr 50% 1fr;
1fr 1fr /* 50% 50% (Maybe) */
1fr 2fr 1fr /* 25% 50% 25% (Maybe) */
25% 1fr 1fr /* 25% 37.5% 37.5% (Maybe) */

minmax()

grid-gap: 10px;

  minmax(200px, 1fr) 200px 200px;

CSS Grid Tips

Want equal width columns with gutter?

You'd think...

.wrapper {
  display: grid;
  grid-template-columns: 25% 25% 25% 25%;
  grid-gap: 10px;
}

But look at what that gives you...

How to get equal width columns with gutter

.wrapper {
  display: grid;
  grid-template-columns: repeat(4, minmax(0, 1fr));
  grid-gap: 10px;
}

Take a look...

Controlling auto-generated rows and columns

.wrapper {
  display: grid;
  grid-template-columns: repeat(3, minmax(0, 1fr));
  grid-template-rows: 100px 100px;
  grid-gap: 10px;

  /* Sets the default height for unspecified rows */
  grid-auto-rows: 50px;
}

Flexbox

Basics and terminology

Flexbox

Best at 1 dimensional and small scale layouts.

  • Can direct flow of content, horizontal/vertical, reverse/regular direction
  • Can distribute extra space many ways
  • Can change displayed order of items
  • Can handle multiple rows/columns, but with less control than CSS Grid

Beginning with Flexbox

Basic syntax

.flex-container {

position

Very useful, and often misused.

Position's Associated Styles

top, bottom, left, right

Change the location of "positioned" elements

z-index

Determines vertical layering of "positioned" elements

position: static;

Position's default value, these elements are not "positioned" so associated styles are ignored.

This is some example text 
.element {
  position: static;
  top: 100px; /* Ignored, because position: static */
  left: 50px; /* Static isn't considered "positioned" */
  float: left;
}
Floated this item so document flow disruption is visible.

position: relative;

Update the element from where it would rendered.

This is some example text 
.element {
  position: relative;
  top: 25px;
  left: 50px;
  float: left;
}
Document flow not disrupted
Also the preferred style to get z-index working

position: absolute;

Update the element based on positioning of a "positioned" parent element

This is some example text 
.element {
  position: absolute;
  top: 0;
  left: 0;
  float: left;
}
Document flow disrupted

position: fixed;

Positions element to the window and element doesn't move when page scrolls.

.element {
  position: fixed;
  top: 100px;
  left: 50px;
}

position: sticky;

Element will stick to defined position when page scrolls

.element {
  position: sticky;
  top: 100px;
  left: 50px;
}

position: sticky; Gotchas

Sticky does not function if:

  • A parent element has overflow set to anything but visible (the default).
  • A parent has a transform set on it.

position: sticky; Gotchas

The sticky element will not leave the content box of it's parent.
